# Absorb log

Append-only. One heading per absorb, in the form `## [YYYY-MM-DD] absorb | what happened`. The linter refuses an entry written any other way, because an entry that is not a heading gets swallowed by the heading above it and every structural read of this file reports the whole span as missing while the prose sits there in full.

This is a pointer, never the record. If a fact only exists in a line here and the page it belongs to still says the old thing, the fact is not absorbed. Write the page.
